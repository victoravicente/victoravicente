### `api-hub-gateway` · Java 21 / Spring Boot 3

> API Gateway corporativo que centraliza o acesso às APIs externas da cooperativa — mTLS, credenciais via HashiCorp Vault, configuração distribuída com Consul, observabilidade com Micrometer/Actuator e documentação automática via Springdoc/Swagger. Um único ponto de entrada para múltiplas integrações, eliminando replicação de lógica de autenticação em cada sistema consumidor.

`Java 21` `Spring Boot 3.4` `mTLS` `HashiCorp Vault` `Consul` `Micrometer` `Swagger`

---

### `integra-fluid` · Python / Django

> Orquestrador de processos de negócio que conecta a plataforma BPM FLUID ao Jira, OCR e outros serviços via Gateway. Cada endpoint encapsula um fluxo completo de múltiplas chamadas HTTP em uma única operação atômica — com rastreamento de execuções, rollback de erros e métricas de automação em banco.

`Python` `Django` `REST APIs` `BPM` `Jira` `OCR` `HashiCorp Vault`

---

### `portal-propensao` · Next.js 14 / Databricks

> Portal web interno para gestores de carteiras, com cache server-side de toda a base analítica do Databricks SQL Warehouse (TTL 24h, paginação em batches), filtros e ordenações client-side por segmento e produto, e agente de análise de crédito por IA integrado via API.

`Next.js 14` `TypeScript` `Databricks` `PySpark` `Tailwind CSS` `LLM`
